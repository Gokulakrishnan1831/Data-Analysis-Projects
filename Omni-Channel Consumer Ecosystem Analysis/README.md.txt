Vrinda Store Annual Sales Analysis (2022)
📌 Project Overview
This project involves a comprehensive sales analysis for Vrinda Store, an omni-channel retail brand. The goal was to transform raw transactional data into an interactive dashboard to help the store manager understand customer behavior and optimize sales strategies for the upcoming year.

📊 Business Insights (Executive Summary)
Based on the 2022 data analysis, the following key insights were uncovered:

Top Performance: March recorded the highest sales and order volume (~2,819 orders).

Target Demographics: Women are the primary drivers of revenue, accounting for 64% of total sales.

Geographic Focus: Maharashtra, Karnataka, and Uttar Pradesh emerged as the top 3 revenue-generating states.

Sales Channels: Amazon, Flipkart, and Myntra are the most influential channels, contributing nearly 80% of total orders.

Key Segment: The "Adult" age group (30-49 years) is the maximum contributing segment (~50% of revenue).

🛠️ Data Processing & Technical Steps
Data Cleaning: * Standardized "Gender" column (Mapping 'M' to 'Men' and 'W' to 'Women').

Handled inconsistent "Quantity" and "Amount" entries.

Created "Age Group" categories (Teenager, Adult, Senior) using nested IF or LOOKUP logic.

Data Analysis:

Utilized Pivot Tables to aggregate sales by month, state, channel, and category.

Developed custom calculations for order-to-sales ratios.

Data Visualization:

Created an Interactive Dashboard featuring Slicers (Monthly, Channel, Category).

Used Bar Charts, Pie Charts, and Line Graphs to represent trends and proportions.

📂 File Structure
Vrinda Sales dashboard.xlsx: The main interactive Excel workbook (Dashboard + Data + Processing).

data/: Original raw CSV/XLSX data files.

screenshots/: Visual snapshots of the final report for quick viewing.

💡 Recommendation
"To maximize 2023 revenue, the store should target female customers aged 30-49 living in Maharashtra, Karnataka, and UP by launching targeted ad campaigns and coupons specifically on Amazon, Flipkart, and Myntra during peak months like March."
