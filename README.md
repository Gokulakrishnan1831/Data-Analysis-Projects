# Data Analysis Projects

A small portfolio of end-to-end analytics projects using **SQL**, **Excel**, and **Power BI**—focused on data cleaning, transformation, KPI reporting, and business insights.

---

## Repository structure

Each folder is a standalone project with its own analysis assets (queries, datasets/inputs if included, and/or dashboard/report files).

- `India Credit Spend SQL Dynamics/` 
- `Omni-Channel Consumer Ecosystem Analysis/`
- `Urban Mobility & Market Shift Analysis/` 

> Branch: `master`

---

## Projects

### 1) India Credit Spend SQL Dynamics (SQL)
**Goal:** Explore credit spend patterns across cities and time using advanced SQL.  
**Skills demonstrated:** window functions, CTEs, KPI-style metrics, growth & trend analysis.

**What you’ll typically find inside**
- SQL scripts/queries for analysis
- Metric definitions and outputs
- Notes or summary of insights (if included)

---

### 2) Omni-Channel Consumer Ecosystem Analysis (Excel)
**Goal:** Understand customer and revenue drivers across multi-channel retail.  
**Skills demonstrated:** advanced Excel formulas, pivot tables, segmentation, trend summaries.

**What you’ll typically find inside**
- Excel analysis workbook(s)
- Cleaned/processed tables (if included)
- Summary insights and charts

---

### 3) Urban Mobility & Market Shift Analysis (Power BI)
**Goal:** Compare mobility usage vs. vehicle sales signals to infer market shifts.  
**Skills demonstrated:** Power Query transformations, data modeling, DAX measures, dashboard storytelling.

**What you’ll typically find inside**
- Power BI report/dashboard file(s)
- Data model/measures documentation (if included)
- Screenshot exports or summary notes (if included)

## Tools & skills used

- **SQL:** joins, aggregations, CTEs, window functions
- **Power BI:** Power Query, DAX, modeling, interactive dashboards
- **Excel:** pivots, advanced formulas, analysis templates

---

## How to use this repo

1. Open a project folder.
2. Read any included notes/docs first (if present).
3. For **SQL projects**: run scripts in your preferred SQL environment (e.g., SQL Server / MySQL / PostgreSQL depending on the script).
4. For **Power BI**: open the `.pbix` file in Power BI Desktop.
5. For **Excel**: open the workbook and review pivot tables / dashboards.

> If datasets aren’t included in a folder, the project can still be reviewed via queries, measures, and dashboard/report logic.
